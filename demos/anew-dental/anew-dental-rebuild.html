What changed

The four things this rebuild fixes

Each one was checked against the practice's live site on 24 July 2026. These are the actual findings, not a generic checklist.

0111 links that all said “Read More”

On the current site

A screen-reader user can pull up a list of every link on a page. On the current site eleven of them say the same two words, so the list is useless and none of them describe where they go.

In this rebuild

Every link now names its destination, for example “Read about treating tooth pain”.

WCAG 2.4.4 Link Purpose, Level A

02A map embedded with no title

On the current site

The Google Map is an iframe with no title attribute, so it is announced only as “iframe” with no indication of what it contains.

In this rebuild

The map is labelled, and the address is also written out as real selectable text with a directions link, so nobody depends on the embed.

WCAG 4.1.2 Name, Role, Value, Level A

03A phone number that could not be tapped

On the current site

The number sat on the page as plain text in places, so a visitor on a phone had to memorise it and retype it into the dialler.

In this rebuild

The number is a real telephone link everywhere it appears, and it is in the header on every screen size.

Usability, and the single most common action on a dental site

04A template old enough to prompt a browser upgrade

On the current site

The current page still ships a legacy “upgrade your browser” notice, which dates the template and adds weight every visitor downloads.

In this rebuild

Rebuilt as hand-written HTML and CSS with no vendor template underneath it.

Performance and credibility

Not measured yet

Colour contrast, keyboard order and a real Lighthouse score need a pass in a live browser, which we record on camera rather than assert here. No score is quoted on this page because we have not measured one.
